Ao iniciar Novo evento, o painel seleciona o local padrao cadastrado na marca. O administrador pode escolher outro local para a edicao. Se o padrao estiver ausente, inativo ou indisponivel, o campo continua vazio para escolha explicita.

O contexto administrativo carrega local_padrao_id tanto para administrador global quanto para membros de marca. Sem migracoes ou alteracoes em registros existentes. Atualiza a versao dos modulos para evitar cache antigo.
