# VISION.md

Vai ter Forró! é uma plataforma para descobrir eventos de forró.

## Missão
Fortalecer a cultura do forró através da tecnologia.

## Visão
Ser a principal referência brasileira para descoberta de eventos de forró.

## Valores
- Comunidade
- Simplicidade
- Confiabilidade
- Cultura Popular
- Acessibilidade

> Onde tem forró hoje?
